# 간편 시작 — 내 PC에서 설정하고 메일 받기

현재 간편 실행과 주간 예약은 Windows를 기준으로 제공합니다. 판정·수집 코드는 기존 CLI와 같습니다.

## 먼저 준비할 것

- Python 3.12 이상: [공식 다운로드](https://www.python.org/downloads/).
- 공공데이터포털 일반 인증키(Decoding). [K-Startup](https://www.data.go.kr/data/15125364/openapi.do)과 [기업마당](https://www.data.go.kr/data/15157820/openapi.do) **각각 활용 신청**이 필요합니다. 현재 코드는 같은 키를 두 서비스에 사용합니다.
- 보고서를 받을 이메일과 **보내는 계정의 SMTP 인증정보**. 주소만 입력하면 발송되는 방식은 아닙니다.
- 사업자등록증 PDF 또는 사진. 직접 입력으로도 시작할 수 있습니다.
- 사진·스캔 PDF 자동 읽기는 Tesseract와 한국어(kor)·영어(eng) 데이터가 필요합니다. [Tesseract 공식 설치 안내](https://tesseract-ocr.github.io/tessdoc/Installation.html)에서 Windows 설치 자료를 확인하세요. 텍스트 PDF는 OCR 없이 읽습니다. Tesseract를 별도로 설치하는 단계는 아직 남아 있습니다.

Gmail의 앱 비밀번호는 [Google 공식 안내](https://support.google.com/accounts/answer/185833?hl=ko)를 따르세요. 계정 정책에 따라 사용할 수 없을 수 있습니다. 일반 로그인 비밀번호를 입력하지 마세요. 기본 메일 방식은 STARTTLS/587이며 SSL 전용 465는 지원하지 않습니다.

## 열기

저장소를 내려받고 압축을 풀거나 clone한 뒤, 루트의 **start-web.cmd**를 실행하세요.

첫 실행은 인터넷으로 Python 의존성을 설치합니다. 이후에는 내 PC의 브라우저에서 회사 정보, API·메일, 실행·예약 화면을 사용합니다. 데이터 폴더나 .env를 내려받아 덮어쓸 필요가 없습니다.

- 웹 전용 환경: .venv-web. 기존 CLI용 .venv는 변경하지 않습니다.
- 기본 주소: http://127.0.0.1:8501
- 기본 접근은 내 PC만 허용합니다. 인터넷에 공개하는 호스팅 구성은 포함하지 않습니다.
- 창을 닫으면 웹 화면은 종료됩니다. 등록한 Windows 예약 작업은 별도로 남습니다.
- 다른 PC에서 복사한 .venv-web는 재사용하지 마세요. 해당 가상환경 폴더만 다른 이름으로 보존한 뒤 다시 실행하면 재설치합니다. 회사 정보와 .env는 별도 파일입니다.

터미널에서 직접 설치·실행하려면:

```powershell
python -m venv .venv-web
.venv-web\Scripts\python.exe -m pip install -e ".[web]"
.venv-web\Scripts\python.exe -m streamlit run src\grant_radar\web_app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

## 화면에서 설정하기

1. **회사 정보**: 등록증을 업로드하고 **문서 읽기**를 누릅니다. 읽힌 상호·업태·종목을 확인하고, 지역·사업자 형태·설립일 등을 채웁니다. 대표자 만 나이와 직원 수는 선택입니다. 모르면 비워두세요.
2. **회사 정보 저장**: 원본과 대조한 뒤 확인란을 체크합니다. 사업자등록증의 개업연월일을 법인 설립일로 자동 대체하지 않습니다. 중소기업·소상공인 여부도 자동 추정하지 않습니다.
3. **API·메일**: API 키, 보내는 계정, 앱 비밀번호, 받는 주소를 입력하고 **연결 정보 저장**을 누릅니다. 저장된 키·비밀번호는 다시 표시하지 않으며 빈칸으로 저장하면 기존 값을 유지합니다.
4. **API 연결 확인**: 각 서비스에서 1건씩 조회합니다. 연결 성공과 전체 공고 수집은 다릅니다.
5. **시험 메일 1통 보내기**: 표시된 수신 주소로 시험 메일을 보냅니다. SMTP 수락 메시지가 도착을 보증하지 않으므로 받은편지함·스팸함에서 확인하세요.
6. **실행·예약**: **지금 공고 찾아보기**로 보고서를 만든 뒤 근거를 확인하고 **이 보고서를 메일로 보내기**를 누릅니다.
7. **자동 메일 켜기**: 자동 발송 동의란을 체크하면 매주 월요일 오전 9시 작업을 등록합니다. **예약 상태 확인**, **자동 메일 끄기**도 같은 화면에 있습니다.

키와 메일 없이 시험하려면 **실행·예약 → 가상 회사로 체험하기**를 사용하세요. 토끼랩과 저장소의 가상 공고를 별도 임시 작업 폴더에서 판정합니다. 실제 설정·운영 DB를 바꾸지 않으며, 체험 결과는 실제 보고서로 메일 발송하지 않습니다.

## 알아둘 범위

- **OCR은 입력 보조입니다.** 오독·누락이 있으므로 저장 전 직접 확인합니다. 자동으로 채워지지 않은 항목을 추정해서 넣지 않습니다. 최대 10MB, PDF 3쪽, 이미지 2,400만 화소까지 지원합니다.
- **대표자 이름·주민번호·사업자등록번호는 판정 입력에 저장하지 않습니다.** 대표자 만 나이를 선택 입력할 수 있습니다. 문서 전문을 펼치면 해당 문서에 있는 개인정보가 화면에 보일 수 있으니 녹화에는 가상 문서를 사용하세요.
- **원본은 장기 보관하지 않습니다.** 업로드 문서와 추출 전문은 브라우저 세션/메모리에서 처리하며, OCR 중 생긴 임시 파일은 라이브러리가 정리합니다. 확인한 회사 정보는 data/company.json, 인증정보는 .env에 저장합니다. .env는 암호화 저장소가 아니므로 PC 계정과 폴더 접근을 관리하세요.
- **메일에는 판정 보고서와 JSON을 첨부합니다.** 사업자등록증은 첨부하지 않습니다. 보고서에는 회사명과 판정에 사용한 회사 값이 포함될 수 있습니다.
- **수집 범위**: 기본 K-Startup 최대 300건, 기업마당 최대 1,700건을 요청합니다. 전체 공고 수집을 보장하지 않으며, 부분 수집은 화면/메일에 표시합니다.
- **자동 실행에는 PC가 필요합니다.** Windows 로그인 세션, 인터넷 연결, 실행 가능한 Python 환경이 있어야 합니다. PC가 꺼져 있으면 그동안 메일은 발송되지 않습니다. 예약 시각을 놓친 작업은 Windows의 StartWhenAvailable로 뒤늦게 실행될 수 있습니다.
- 주간 실행은 해당 폴더의 data/company.json 및 data/company_*.json을 모두 판정합니다. 로컬 웹 예약은 폴더별 이름을 사용하며 예전 수동 등록 작업을 지우지 않습니다. 이미 예약을 운영 중이면 중복 등록 여부를 먼저 확인하세요.
- 브라우저 **지금 공고 찾아보기**는 모집 중 공고를 보고, 주간 메일은 기존 방식대로 지난 성공 이후 신규 공고를 봅니다. 같은 시점에도 두 결과 수는 다를 수 있습니다.
- 실행 중 언어모델이나 유료 OCR API를 호출하지 않습니다. 문서 내용은 외부 OCR 서비스로 전송하지 않습니다.

## 참고한 기존 해결책과 검증 구분

- [Streamlit](https://github.com/streamlit/streamlit) (Apache-2.0): 로컬 입력 폼·비밀번호 입력·업로드·보고서 표시. 별도 프런트엔드와 서버를 새로 만드는 부담을 줄이기 위해 선택.
- [pypdf](https://github.com/py-pdf/pypdf) (BSD-3-Clause): PDF 텍스트 추출. 이미지 속 글자를 읽는 OCR은 별도임.
- [pypdfium2](https://github.com/pypdfium2-team/pypdfium2): 스캔 PDF 페이지를 OCR용 이미지로 변환. PDFium 및 의존 구성요소의 라이선스는 해당 프로젝트 안내 참조.
- [pytesseract](https://github.com/madmaze/pytesseract) / [Tesseract](https://github.com/tesseract-ocr/tesseract) (Apache-2.0): 기존 로컬 OCR 방식을 재사용. Windows 기본 설치 경로와 PATH를 확인하며 kor+eng 지원 여부를 검사.

문서에 설명된 기능과 실제 사용자 문서의 인식 정확도는 다릅니다. 회사별 자격 정확도·모든 등록증 양식·메일 도착률은 보장하지 않습니다. 자동 테스트는 가상 회사·문서와 모의 네트워크/메일을 사용합니다.
